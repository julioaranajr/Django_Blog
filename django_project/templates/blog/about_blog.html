About This Blog

This blog is created using Django framework, bootstrap and crispy forms.

The blog application that allows users to create, read, update, and delete blog posts.

It also allows users to register an account, login, logout, reset password, and change password.

It is created for educational purposes only.


Features

  • View all blog posts
  • View individual blog post
  • Register an account
  • Login to your account
  • Create a new blog post
  • Update your profile
  • Change your password
  • Reset your password
  • Logout
